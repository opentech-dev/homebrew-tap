# Tesseract — Homebrew tap

Install [Tesseract](https://tesseract.dev), the free AI agent app by Eightcell Labs, Inc., with Homebrew:

```sh
brew install --cask opentech-dev/tap/tesseract-ai
```

The app updates itself after that. Downloads for Windows and Linux: [tesseract.dev](https://tesseract.dev).

Tesseract is not affiliated with Tesseract OCR (Homebrew's `tesseract` formula), Tesseract by Mirage, or any other
product named Tesseract.
